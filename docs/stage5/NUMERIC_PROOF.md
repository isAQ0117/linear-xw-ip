# 独立指数优化与有限位宽证明

非零最大值V满足2^H≤V<2^(H+1)。在原Golden起始H−17，最大项缩放≥131072，其RNE不可能≤131071，故必加至少一次。候选H−16时所有幅值<131072，最大项≥65536，RNE至多131072；若溢出，指数再加1后所有幅值<65536，RNE≤65536，必合法。因此优化与原从H−17顺序搜索的第一个合法指数完全一致；只需0/1次额外retry。不以浮点数或随机实验替代该区间证明。

对于每个非零输入，e+floor(log2(abs(m)))≤H，故e−candidate≤16−floor(log2(abs(m)))≤16；若左移，结果<2^17，18bit无符号幅值足够。输入-2^47的幅值2^47在48bit无符号补码取绝对值后正确。指数使用signed18：H∈[-32768,32814]，candidate∈[-32784,32798]，最终≤32799；与原e之差∈[-65551,65567]，signed18足够。移位器只接合法5/6bit段，不接18bit未经界限检查的shift。

右移1..47时a=q*2^d+r，guard=r[d−1]，sticky=OR(r[d−2:0])，进位=guard&&(sticky||q[0])。符号最后恢复，所以负tie与正tie严格对称。d≥48时a≤2^47，只有a=2^47,d=48达到0.5，偶0胜出；其余均<0.5，全部输出0。m=0首先处理，极端零指数不触发无意义左移。

retry必须重新读取原m/e。反例Group [(262143,0),(5,-1)]：候选1时第二项5/4→1；最终2时5/8→1；若再对已舍入1除2，则tie取0，错误。正负版本均测试。

最终才检查signed8：262143*2^-130，H=-113，candidate=-129；首次131072溢出，最终-128、65536合法。初值超界不报错；最终超界33。

非零Group整体量化后全零在本算法下不可能：最终最大幅值至少65536（候选合法）或65536（retry边界）。小项可全部变零，最大项不可能消失。测试断言此不变量，并覆盖组内小项下溢为0；不捏造“非零Group整体量化为0”的PASS。

证明覆盖完整字段域；实验不等于形式化穷举signed48×signed16。实际执行见logs/numeric.log：5188组、188retry、2050最终范围错；另262144个signed18输入穷举。Independent Golden用Fraction精确值区间搜索和Fraction.__round__，不导入生产numeric；硬件原型用有界整数guard/sticky；旧numeric字节不变。
